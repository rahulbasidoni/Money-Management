Introduction

Money Management is a personal finance management website that I developed to make managing money easier and more organized.
Many people find it difficult to keep track of their daily expenses, understand where their money goes, and maintain good financial habits.
Money Management aims to solve this problem by bringing important financial management features together in one platform. 
Instead of maintaining expense records manually, users can use this website to add their expenses, manage their financial activities, compare spending, and understand 
their money habits through a simple and user-friendly interface.

What Can You Do With Money Management?

Money Management provides different features to help users manage their personal finances. 
Users can create an account, log in, and access their personal finance dashboard. 
They can add their expenses and keep track of their spending activities. 
The expense management section helps users maintain their financial records, while the comparison feature helps them understand differences in their spending. 
The application also includes a financial AI assistant designed to make finance-related interactions easier through simple conversations.

How I Built It

I developed Money Management using HTML, CSS, and JavaScript. HTML is used to create the structure of the website, CSS is responsible for its appearance and layout
 and JavaScript handles the interactive features and functionality. I integrated Supabase for backend services and user authentication, including email verification. 
 GitHub is used to maintain the project's source code and track development changes, while Vercel is used for deployment.

Main Pages

Home Page: The main entry point of the website, where users can access its features.

Login Page: Allows existing users to access their accounts.

Email Verification: Helps verify users' email addresses.

Add Expense: Allows users to enter and record their expenses.

Expenses Page: Provides access to recorded expense information.

Compare Page: Helps users compare their financial spending.

Technologies Used

HTML5 – For webpage structure.

CSS3 – For styling and layout.

JavaScript – For functionality and user interactions.

Supabase – For backend integration and authentication.

Git and GitHub – For source code management and version control.

Vercel – For hosting and deployment.

What I Learned

While developing Money Management, I gained practical experience in frontend development, JavaScript interactions, backend integration, user authentication, and connecting a website with Supabase. 
I also learned how to organize project files, manage development changes using Git, and deploy a website using Vercel. This project helped me understand how different technologies work together to build a functional web application.

Future Improvements

I plan to improve Money Management by introducing more advanced financial graphs, monthly and yearly spending reports, budget planning, personalized financial insights, and a more interactive AI financial assistant.
These improvements will make the application more useful for users who want to understand and manage their finances effectively.
